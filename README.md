# میز پژوهش اورون

دستیار پژوهشی برای تحلیل خودکار مقالات علمی، ساخت کتابخانهٔ ماندگار و پرسش از کل منابع.

## چه کار می‌کند

- **تحلیل مقاله** — چکیده یا متن کامل را می‌گیرد، با Claude می‌خواند و فیلدهای قالب انتخابی را استخراج می‌کند.
- **کتابخانه** — هر مقالهٔ تحلیل‌شده در Postgres ذخیره می‌شود؛ جستجو و فیلتر دارد.
- **پرسش از کل کتابخانه** — سؤال می‌پرسید و پاسخ فقط از روی مقالات ذخیره‌شده ساخته می‌شود، با ارجاع به شمارهٔ هر مقاله.
- **قالب استخراج دلخواه** — سه قالب آماده (شیمی دارویی، بالینی، عمومی) و امکان ساخت قالب شخصی.
- **خروجی** — CSV برای اکسل و Markdown برای ورد.

## راه‌اندازی

```bash
npm install
export DATABASE_URL="postgres://…"        # رشتهٔ اتصال Neon
export ANTHROPIC_API_KEY="sk-ant-…"       # کلید از console.anthropic.com
npm start
```

جدول‌ها و دادهٔ پایه بار اول که سرور بالا می‌آید خودکار ساخته و پر می‌شوند.

## متغیرهای محیطی

| متغیر | لازم | توضیح |
|---|---|---|
| `DATABASE_URL` | بله | رشتهٔ اتصال Postgres روی Neon |
| `ANTHROPIC_API_KEY` | برای بخش هوشمند | بدون آن، کتابخانه و خروجی کار می‌کنند ولی تحلیل و پرسش نه |
| `CLAUDE_MODEL` | خیر | پیش‌فرض `claude-sonnet-5-5` |
| `PORT` | خیر | پیش‌فرض ۳۰۰۰ |

## ساختار

```
server.js        API و سرو فایل‌های ایستا
db.js            اتصال، ساخت جدول‌ها، قالب‌های پیش‌فرض، پر کردن اولیه
data/            کتابخانهٔ پایه: ۵۹ مقاله، ۲۱۶ ترکیب، نتایج DFT
public/          رابط کاربری فارسی
```
