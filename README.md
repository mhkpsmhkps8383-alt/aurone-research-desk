# دستیار هوشمند

کتابخانهٔ مقالات علمی با افزودن مستقیم فایل. هیچ سرویس بیرونی و هیچ کلید API لازم ندارد.

## چه کار می‌کند

- **افزودن فایل** — فایل PDF، Word یا متن را می‌گیرد، متنش را در خود مرورگر می‌خواند و عنوان، DOI و سال را از متن بیرون می‌کشد. شما اصلاح می‌کنید و ذخیره می‌زنید.
- **کتابخانه** — هر مقاله در Postgres ذخیره می‌شود؛ جستجو و فیلتر دارد.
- **قالب فیلد دلخواه** — سه قالب آماده (شیمی دارویی، بالینی، عمومی) و امکان ساخت قالب شخصی برای فیلدهایی که می‌خواهید پر کنید.
- **خروجی** — CSV برای اکسل و Markdown برای ورد.

## راه‌اندازی

```bash
npm install
export DATABASE_URL="postgres://…"        # رشتهٔ اتصال Neon
npm start
```

جدول‌ها و دادهٔ پایه بار اول که سرور بالا می‌آید خودکار ساخته و پر می‌شوند.

## متغیرهای محیطی

| متغیر | لازم | توضیح |
|---|---|---|
| `DATABASE_URL` | بله | رشتهٔ اتصال Postgres روی Neon |
| `PORT` | خیر | پیش‌فرض ۳۰۰۰ |

## ساختار

```
server.js        API و سرو فایل‌های ایستا
db.js            اتصال، ساخت جدول‌ها، قالب‌های پیش‌فرض، پر کردن اولیه
data/            کتابخانهٔ پایه: ۵۹ مقاله، ۲۱۶ ترکیب، نتایج DFT
public/          رابط کاربری فارسی
```
